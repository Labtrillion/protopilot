# 데모 시나리오 명세

Brev의 관제 화면에서 재생할 수 있는 다섯 가지 시나리오의 조작과 알람 기준을 다룹니다.

## 실행용 시나리오 JSON

관제 화면의 **시나리오 → 데모 시나리오**에서 아래 5개 중 하나를 선택합니다. **불러와 재실행 준비**를 누르면 공정 시간 0분에서 일시정지된 새 실행이 만들어집니다. **실행**을 누르면 JSON에 적힌 시각에 조작이 적용되고 `duration_min`에서 다시 일시정지합니다.

| 시나리오 | 실행 파일 | 공정 시간별 조작 | 종료 |
| --- | --- | --- | ---: |
| 1. 경제 운전 중 밸브 스틱션 | [시나리오 1 JSON](s1-economic-then-stiction.json) | 0분 원료 조성 외란 IDV(8) · 30분 반응기 압력 목표 2800 kPa(g) · 180분 반응기 냉각수 밸브 스틱션 IDV(14) | 480분 |
| 2. 고온 오경보 | [시나리오 2 JSON](s2-false-high-temp.json) | 120분 반응기 온도 표시값에 +32 °C 오프셋 적용 · 122분 해제 | 300분 |
| 3. 냉각 조건 회복 | [시나리오 3 JSON](s3-restore-after-cooling.json) | 0분 냉각 외란 IDV(27) · 60분 생산량 목표 21.8 m³/h | 720분 |
| 4. 원료 조성·두 설비의 냉각 조건 변동 | [시나리오 4 JSON](s4-composition-and-two-coolers.json) | 60분 원료 조성과 냉각 외란 IDV(8)·IDV(11)·IDV(12) 동시 적용 | 480분 |
| 5. 교대 뒤 생산 목표 불일치 | [시나리오 5 JSON](s5-shift-plan-mismatch.json) | 30분 이전 교대의 증산 목표 25.2 m³/h 적용 | 360분 |

### 데모 알람 기준

시나리오 1·3·4·5는 `alarm_limits`의 데모용 편차 기준을 시작 시점에 적용합니다. 외란 없이 12시간 운전한 기본 시드(`1431655765`)의 관측 범위를 참고해 기준을 설정했습니다. 예약 조작 없이 시나리오를 재생하면 알람이 발생하지 않습니다.

| 시나리오 | 기준 | 목적 |
| --- | --- | --- |
| 1 | 반응기 온도 120.2–120.6 °C, 반응기 압력 상한 2850 kPa(g), 분리기 액위 40–56%, 스트리퍼 액위 30–60% | 밸브 스틱션(IDV(14))이 추가된 뒤 반응기 온도 알람이 발생합니다. |
| 2 | 기본 기준 | 온도 표시값이 반응기 온도 상한(150 °C)을 넘으면 알람이 발생하고, 2분 뒤 해제됩니다. |
| 3 | 반응기 온도 120.25–120.55 °C | 온도 알람이 발생한 뒤 냉각 조건이 잠시 안정되는 구간을 관찰할 수 있습니다. |
| 4 | 반응기 압력 상한 2725 kPa(g), 반응기 온도 119.9–120.9 °C, 분리기 액위 43–55%, 스트리퍼 액위 37–60% | 반응기와 후단 설비에서 차례로 알람이 발생합니다. |
| 5 | 스트리퍼 액위 35–60%, 반응기 냉각수 출구 온도 하한 94.1 °C, 분리기 액위 43–56% | 증산 목표가 적용된 뒤 냉각수 온도와 액위 알람이 발생합니다. |

모든 데모 시나리오는 240배속으로 시작합니다. 알람 판정 간격은 공정 시간 기준으로 240배속에서 2.4분, 960배속에서 9.6분입니다. 기본 배속에서 아래 알람 시각을 재현할 수 있습니다.

기본 시드와 240배속으로 [재생 회귀 테스트](../../tests/test_scenario_alarms.py)의 실행기를 돌려 아래 알람을 확인했습니다.

| 시나리오 | 관측된 알람 |
| --- | --- |
| 1 | 204.0분부터 반응기 온도 알람이 반복 (480분까지 30건) |
| 2 | 120.0분 반응기 온도 상한 (152.4 °C), 122.0분 해제 |
| 3 | 98.4분 · 112.8분 · 194.4분 반응기 온도 → 194.4분 알람 이후 384.0분에 다시 발생 |
| 4 | 88.8분 반응기 온도 → 148.8분 반응기 압력 → 247.2분 스트리퍼 액위 → 345.6분 반응기 압력 → 420.0분 분리기 액위 |
| 5 | 235.2분 반응기 냉각수 출구 온도 → 252.0분 분리기 액위 → 278.4분 스트리퍼 액위 |

시나리오 4의 345.6분 반응기 고압 경고에서 README의 Zoro 대응 검토를 재현할 수 있습니다. [Brev 시나리오 4 검증 결과](../../README.md#시나리오-4-검증-결과)

### 형식 (`protopilot-scenario-1`)

```json
{
  "format": "protopilot-scenario-1",
  "duration_min": 300,
  "alarm_limits": {"XMEAS(7)": [null, 2725]},
  "events": [
    {"at_min": 120, "op": "offset", "id": "XMEAS(9)", "value": 32, "duration_min": 2}
  ]
}
```

- `events`의 조작 시각은 `at_min`으로 입력한다. `op`, `id`, `value`, `low`는 라이브 시나리오(`protopilot-live-1`)의 조작과 같다. 지원하는 조작은 `mv`, `setpoint`, `disturbance`, `offset`, `limit`, `pressure_test`, `controller`, `speed`다.
- `duration_min`을 적은 조작은 그만큼 지난 뒤 되돌린다. 외란·오프셋은 0, 설정값·밸브는 기본값·자동, 알람 기준은 기본 기준으로 돌아간다.
- `seed`, `controller`, `initial_speed`를 생략하면 기본 시드, 기본 제어 옵션, 960배속을 쓴다.
- `title`은 관제 화면의 시나리오 이름입니다. `context`, `agent`, `assumptions`는 설계 메모입니다. Zoro 대응 검토에는 알람 체크포인트의 계측·설정값·조작 이력과 SOP·문헌 검색 결과를 사용합니다.
- 변환은 [server/minute_scenario.py](../../server/minute_scenario.py), 회귀 테스트는 [tests/test_minute_scenario.py](../../tests/test_minute_scenario.py)와 [tests/test_scenario_alarms.py](../../tests/test_scenario_alarms.py)에 있다.
